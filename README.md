# 连锁挖矿(Chain Break)

一个 Minecraft **Fabric** 模组，按住激活键（默认 `` ` ``）挖掘即可一次性挖掉相连的方块，对齐 FTB Ultimine 的核心体验。单人存档用。

## 下载

## 特性

- **6 种形状**：无形状（矿脉 BFS）/ 小型通道 / 大型通道 / 小型方形 / 逃生通道 / 采矿通道
- **形状菜单**：按住 `` ` `` 在屏幕左上角显示面板，`` ` `` + Shift 展开形状列表，Shift + 鼠标滚轮切换
- **实时预估**：面板显示准星指向的方块名、当前形状将破坏的方块数、以及最低工具要求（✓/✗）
- **方块线框预览**：按住 `` ` `` 时，所有将被连锁的方块显示白色线框（准星瞄准的那一格也会画上）
- **掉落方式**：原地掉落 / 直接进背包 / 掉到玩家脚下（可配置）
- **挖树连带挖树叶**：挖原木时把连通的整冠树叶一起收掉，不会连到旁边另一棵树（可开关）
- **农作物按成熟度区分**：挖成熟的小麦只会连锁同样成熟的小麦，没熟的不会跟着被铲掉
- **收割自动补种**：连锁收完作物自动扣种子补种；砍树也会在树基补回对应树苗（可开关）
- **一键连锁种植**：按住 `` ` `` 右键点一下种子，3×3 一次种一片（可开关）
- **配置界面**：背包 / 创造物品栏左上角 ⚙ 按钮，或按 `K` 打开；客户端和服务端选项已合并成一页，数字栏可以直接鼠标拖选改值
- **完整配置项**：单次最大方块数、饥饿消耗、经验消耗、冷却、工具耐久保护、方块黑名单、触发方式等
- 改动即时保存，退出游戏也不会丢设置

## 按键

| 按键              | 功能            |
| --------------- | ------------- |
| `` ` ``（默认）     | 启用连锁挖矿 / 显示面板 |
| `` ` `` + Shift | 展开形状菜单        |
| Shift + 滚轮      | 切换形状          |
| `K`             | 打开配置界面        |
| `[` / `]`       | 切换形状（备用）      |

均可在「选项 → 控制 → 按键绑定」里改。

## 配置

游戏内按 `K` 或点界面左上角 ⚙ 打开配置界面。

也可以直接编辑 `config/chainbreak.properties`，重启游戏后生效。

## 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/)（0.19.5+）和 [Fabric API](https://modrinth.com/mod/fabric-api)（0.140.0+）；
2. 将 jar 放入实例的 `mods/` 目录；
3. 启动游戏。

> 同一个 mod id 只能存在一份 jar，升级时请先删掉旧版本，否则加载会报重复 id。
